# Rev Cycling website

Open `index.html` in a browser. Pages (Home, About us, Activities, Services, Contact us) are switched with the menu, no server needed.

- `css/style.css`: all styles. Brand colors are --or (#fc4b02) and --te (#02819b) at the top.
- `js/config.js`: **edit this to change images and tour/team content.** Copy your photos into `assets/images/` using the names listed in `assets/images/PUT-YOUR-PHOTOS-HERE.txt`.
- `js/main.js`: slideshow, page switching, animations, and the dummy tour/team/service data.
- `assets/logo.png`, `logo-mark.png`, `favicon.ico`, `favicon-32.png`, `apple-touch-icon.png`: your Rev Cycling logo and icons.
- `assets/images/`: placeholder illustrations. Replace with real photos.

Fonts (Anton, Outfit, Bricolage Grotesque) load from Google Fonts, so they need an internet connection.
The contact form is a demo and does not send anything.
